# Security policy

This project is an early MVP and has not received an independent security audit. Only the
current 0.1 development line is maintained. Review THREAT_MODEL.md before deployment.

Report vulnerabilities privately through GitHub:
<https://github.com/prollysamz/agentguard/security/advisories/new>. Do not open a public
issue for a vulnerability. Do not include credentials, personal data or a working exploit
against a live third-party system in any report.

A useful report includes the affected version, a minimal local reproduction, expected and
observed enforcement behavior, and whether an unapproved side effect occurred. Use synthetic
credentials and temporary files. Do not test against resources you do not own.
